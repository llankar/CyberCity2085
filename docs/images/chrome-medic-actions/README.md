# Chrome medic — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques : attente 16, marche 32, mêlée 16, couvert 16, impact 16, état au sol 16 et soin 16.
- Tir et PSI sont non applicables : aucune arme à feu ; soin cybermédical technologique, non PSI.
- `audit.json` compte 18 ensembles complets sur 231 et aucun ensemble partiel.
- `animation-report.json` et les 40 captures `chrome-medic-*` proviennent de la scène tactique réelle.

Les huit planches ont été générées en mode ImageGen intégré depuis la référence. Les prompts imposaient identité, blouse blanche, membres chromés, effet de soin cyan compact, huit orientations, poses distinctes et transparence, sans fausse arme, miroir, rotation mécanique, socle ni décor.
