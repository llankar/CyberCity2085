# Robot de combat — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques, huit orientations, sept actions applicables complètes.
- PSI et soin sont non applicables à ce châssis de combat sans capacité PSI ou médicale.
- `audit.json` compte 6 ensembles complets sur 231 et aucun ensemble partiel.
- Les 40 captures d'action proviennent de la scène tactique réelle.

Les cinq planches ont été générées en mode ImageGen intégré, fond transparent : recul du canon d'épaule, balayage mécanique, couvert, stabilisation et arrêt sûr. Les prompts imposaient des poses réellement distinctes, sans miroir, socle, décor ni fausse extrusion.
