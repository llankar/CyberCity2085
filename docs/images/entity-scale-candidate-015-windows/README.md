# Candidat uniforme 0,015 — diagnostic intermédiaire

Onze planches couvrent les 122 cartes avec un override uniforme 0,015, sans modification de production. Le résultat corrige les extérieurs mais réduit excessivement certains intérieurs et environnements industriels. Cette passe a conduit au profil final différencié : 0,015 pour urbain/wasteland et 0,020 pour intérieur/industrie.
