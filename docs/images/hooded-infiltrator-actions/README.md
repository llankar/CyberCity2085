# Infiltrateur encapuchonné — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 112 frames authentiques : attente 16, marche 32, mêlée 16, couvert 16, impact 16 et état au sol 16.
- Huit orientations par action ; deux poses distinctes pour les actions brèves et quatre pour la marche.
- Tir, PSI et soin sont non applicables : l’infiltrateur porte deux lames, sans arme à distance, capacité PSI ni matériel médical.
- `audit.json` compte 10 ensembles complets sur 231 et aucun ensemble partiel.
- `animation-report.json` et les 32 captures `hooded-infiltrator-*` proviennent de la scène tactique réelle.

Les sept planches ont été générées en mode ImageGen intégré à partir de l’illustration de référence. Les prompts imposaient l’identité, les deux lames, le manteau tactique effiloché, huit orientations, des poses réellement distinctes et un fond transparent sans miroir, rotation, socle ni décor.
