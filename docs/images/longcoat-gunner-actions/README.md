# Mitrailleur au long manteau — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques : attente 16, marche 32, tir 16, mêlée 16, couvert 16, impact 16 et état au sol 16.
- Huit orientations par action ; deux poses distinctes pour les actions brèves et quatre pour la marche.
- PSI et soin sont non applicables : le personnage est un mitrailleur sans capacité PSI ni matériel médical.
- `audit.json` compte 10 ensembles complets sur 231 et aucun ensemble partiel.
- `animation-report.json` et les 40 captures `longcoat-gunner-*` proviennent de la scène tactique réelle.

Les huit planches ont été générées en mode ImageGen intégré à partir de l’illustration de référence. Les prompts imposaient l’identité, le long manteau noir à liserés ambre, l’arme lourde, huit orientations, des poses réellement distinctes et un fond transparent sans miroir, rotation, socle ni décor.
