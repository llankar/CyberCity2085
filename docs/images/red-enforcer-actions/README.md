# Red enforcer — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques : attente 16, marche 32, tir 16, mêlée 16, couvert 16, impact 16 et mort 16.
- PSI et soin sont non applicables.
- `audit.json` compte 22 ensembles complets sur 231 et aucun partiel.
- Les 40 captures proviennent de la scène tactique réelle.

Les huit planches ont été générées en mode ImageGen intégré depuis la référence, avec identité, viseur rouge, manteau noir/rouge, arme unique, huit orientations, poses distinctes et alpha imposés, sans miroir, rotation mécanique, socle ni décor.
