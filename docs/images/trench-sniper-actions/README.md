# Tireur au manteau — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques : attente 16, marche 32, tir 16, mêlée 16, couvert 16, impact 16, mort 16.
- Huit orientations par action ; deux poses distinctes pour les actions brèves et quatre pour la marche.
- PSI et soin sont non applicables à ce tireur sans rôle PSI ni capacité médicale.
- `audit.json` compte 3 ensembles complets sur 231 et 3 ensembles partiels.
- `animation-report.json` et les 40 captures `sniper-*` proviennent de la scène tactique réelle.

Les planches et leurs SHA-256 sont conservés sous `assets/combat_visual/source_sheets/agent_diverse_04_trench_sniper/` et dans le manifeste.
