# Twin-blade adept — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 112 frames authentiques : attente 16, marche 32, mêlée, couvert, impact et mort, 16 chacune.
- Tir, PSI et soin sont non applicables.
- Audit : 24/231 ensembles complets, zéro partiel ; 32 captures issues de la scène tactique réelle.

ImageGen intégré a conservé l’undercut violet, le manteau noir/violet et exactement deux lames énergétiques, avec huit orientations et alpha, sans miroir, rotation, socle ni décor. Une marche arrière à volutes parasites a été rejetée et régénérée.
