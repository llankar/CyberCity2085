# Captures réelles — UI Visual Unification

Captures du framebuffer Arcade, à leur résolution native. Les WebP sont encodés sans perte : les pixels RGB décodés ont été comparés aux PNG originaux. Aucune image de maquette ne remplace une interface. Les campagnes et résultats affichés viennent de fixtures isolées du jeu.
