# Yellow strike — actions applicables complètes

Validation native Windows du 19/11/2026 avec Godot 4.6.3 et NVIDIA RTX 5070 Ti.

- 128 frames authentiques : attente 16, marche 32, tir 16, mêlée 16, couvert 16, impact 16 et état au sol 16.
- PSI et soin sont non applicables : aucun pouvoir PSI ni équipement médical.
- `audit.json` compte 20 ensembles complets sur 231 et aucun ensemble partiel.
- `animation-report.json` et les 40 captures `yellow-strike-*` proviennent de la scène tactique réelle.

Les huit planches ont été générées en mode ImageGen intégré depuis la référence. Les prompts imposaient l’identité, le carré noir, le long manteau tactique noir à doublure jaune, une seule arme fine, huit orientations, des poses distinctes et le canal alpha, sans miroir, rotation mécanique, socle ni décor.
